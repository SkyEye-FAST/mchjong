# Rule references

The Mahjong Soul ancient-yaku example uses the award names, values and conditions
published in the official client's `fan` and `fandesc` tables, version
`0.11.252.w`, reviewed on 2026-10-11:

- [Official client configuration](https://game.maj-soul.com/1/v0.11.252.w/res/config/lqc.lqbin)
- [Configuration schema](https://game.maj-soul.com/1/v0.10.1.w/res/proto/config.proto)

The example's descriptions and declarative implementation are written for MChjong;
no client code, images, sounds or configuration archive is distributed. The four
contained-award exclusions are MChjong's explicitly selected scoring policy;
the public configuration does not specify those relationships. See
[Rules](docs/RULES.md#custom-riichi-and-taiwan-awards) for the playable definitions.
