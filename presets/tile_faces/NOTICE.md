# Tile-face artwork notices

This notice covers the Kansai, Kanto, Sichuan, Hong Kong, Taiwan and Fujian
artwork in this directory. Each preset contains 45 transparent PNG engravings
and one `theme_metadata.json` definition.

## Original artwork

The Kanto, Sichuan, Taiwan and Fujian face presets are complete original redraws created for
MChjong. Each contains its own ordinary, red-five and flower engravings.

## Resource files

This directory is the single source for the images, preset definitions and
attribution packaged with MChjong. The definitions include the source metadata.
Texture layout, flower ordering and resource-pack customization are documented
in the [artwork contract](../../docs/ASSETS.md).
